# Quick Start Guide for Instructors

**Get the workshop running in 30 minutes**

---

## 🚀 30-Minute Setup

### Step 1: Review Materials (5 min)

```
READ THESE FIRST:
1. README.md - Overview of entire workshop
2. Facilitator-Guide.md - Pre-workshop prep checklist
3. Day1-Content.md - What you'll teach Day 1
```

### Step 2: Confirm Student Access (10 min)

**Before the workshop:**
- [ ] Confirm an institution-approved AI chat tool students can access
- [ ] Confirm whether a document-grounded workspace is available (NotebookLM is one option)
- [ ] Treat provider accounts and custom-assistant features as optional; access and limits vary
- [ ] Do not require paid plans, API keys, or personal account connections

Share the approved tool links and access guidance. Do not collect student passwords or create accounts on students' behalf.

### Step 3: Download Materials (5 min)

Download this folder to your computer:
- Keep all files organized
- Print Day 1-2 content for students
- Have digital copy to share via LMS

### Step 4: Test Everything (10 min)

**On your computer, test:**
- [ ] All AI tool links work
- [ ] Internet connection stable
- [ ] Confirm students can participate with approved tools or the prepared no-login backup
- [ ] Projector connected
- [ ] Audio working
- [ ] Video playback working

**Done!** Ready to teach!

## 📅 5-Day Teaching Plan

### Day 1: Introduction to AI

**Time Allocation (4 scheduled hours including the break):**
- 30 min: AI, ML, and GenAI (Concepts)
- 45 min: How GenAI Works (15 min concepts + 30 min guided demo)
- 15 min: Break
- 60 min: Explore approved AI tools (Guided hands-on)
- 45 min: Code, image, audio, or presentation examples (Guided hands-on)
- 45 min: Interactive AI challenge (Activity)

**Key Materials:**
- `content/Day1-Content.md` - Full lecture notes
- `slides/Day1-GenAI-Foundations.html` - Browser-based slide deck with conversational Tanglish presenter notes (`N` toggles notes)
- `content/Speaker-Notes-Day1.md` - Separate detailed Tanglish speaking script for the full Day 1 session
- `activities/Day1-Activities.md` - 5 activities for students
- `resources/AI-Glossary.md` - Terms to use
- `resources/AI-Tools-Comparison.md` - Which tool for what

**Prep:**
- [ ] Read all of Day1-Content.md
- [ ] Open the Day 1 slide deck and test keyboard navigation
- [ ] Test approved tools and a backup demonstration
- [ ] Have 3-5 sample prompts ready
- [ ] Select an approved media-generation tool for an optional demonstration
- [ ] Print activities handout

**In Class:**
- Start with: "AI is everywhere" examples
- Show: Bad prompt → Good prompt comparison
- Have students: Try creating 3 prompts each
- End with: "Tomorrow we get serious with prompts!"

---

### Day 2: Prompt Engineering

**Time Allocation (4 scheduled hours including the break):**
- 30 min: Prompting foundations (Concepts)
- 75 min: Prompting techniques workshop (Guided hands-on)
- 15 min: Break
- 30 min: Checkable explanations and iteration (15 min concepts + 15 min practice)
- 45 min: AI for CS study and careers (Guided hands-on)
- 45 min: Prompt challenge (Activity)

**Key Materials:**
- `content/Day2-Content.md` - Full lecture notes
- `resources/Prompt-Engineering-Guide.md` - Complete guide (print for students)
- Sample prompts throughout

**Prep:**
- [ ] Read Day2-Content.md
- [ ] Prepare 5 bad/good prompt pairs
- [ ] Have competition prompts ready
- [ ] Prepare prizes for competition (optional)

**In Class:**
- Show: 5 iterations of the same prompt
- Have students: Write and compare prompts in pairs
- Competition: Which student writes the BEST prompt?
- End with: Students have personal toolkit

---

### Day 3: Build Project 1

**Time Allocation (4 scheduled hours including the break):**
- 45 min: Document-grounded AI concepts and demonstration
- 90 min: Guided project development (Hands-on)
- 15 min: Break
- 45 min: Continue project and verify sources (Hands-on)
- 45 min: Demonstration, peer review, and reflection (Activity)

**Key Materials:**
- `projects/Project1-CS-Course-Assistant.md` - Full project guide
- Approved CS course sources (prepare 2-4 documents on one topic)
- NotebookLM or approved equivalent (have a backup demonstration ready)

**Prep:**
- [ ] Read Project1-CS-Course-Assistant.md
- [ ] Select 2-4 permitted sources on a focused CS topic
- [ ] Add approved sample CS material to the selected document workspace
- [ ] Create a demo document-grounded workspace
- [ ] Test supported and unsupported questions against source material
- [ ] Have backup screenshots ready

**In Class:**
- Show a live or prepared document-grounded demo
- Students add approved sources if they have access
- Students test supported, synthesis, and out-of-scope questions
- Students document findings and verify cited sources
- End with: Students have a tested, document-grounded study workspace and understand it is not a custom standalone app

---

### Day 4: AI Workflows & Agents (Optional Automation Build)

**Time Allocation:**
- 45 min: Chatbots vs Agents (Lecture)
- 60 min: Guided workflow design (Hands-on)
- 15 min: Break
- 75 min: Optional platform prototype or workflow simulation (Hands-on)
- 45 min: Test with synthetic data and reflect (Activity)

**Key Materials:**
- `content/Days3-5-Summary.md` - Day 4 section
- Workflow diagram and synthetic feedback examples

**Prep:**
- [ ] Read Day 4 section in Days3-5-Summary.md
- [ ] Prepare a workflow diagram and synthetic feedback examples
- [ ] If appropriate, test one approved automation platform and a backup demo
- [ ] Do not connect real student records, personal accounts, or unapproved services

**In Class:**
- Show: How workflow works (video or live)
- Explain why a fixed workflow is not automatically an AI agent
- Design a trigger/action/review flow using synthetic feedback data
- Students may prototype the workflow if accounts and permissions are available
- End with: Students understand the workflow and its risks; a live automation is optional

---

### Day 5: Final Project + Careers

**Time Allocation (4 scheduled hours including the break):**
- 45 min: Project brief, responsible use, and career context
- 90 min: Guided project development
- 15 min: Break
- 45 min: Peer testing and refinement
- 45 min: Demonstrations and CS careers discussion

**Key Materials:**
- `projects/Project2-CS-Career-Assistant.md` - Project build guide
- `content/Days3-5-Summary.md` - Career paths and responsible AI
- Sample career assistant prompt
- Job posting examples
- Career exploration resources

**Prep:**
- [ ] Read Day 5 section thoroughly
- [ ] Prepare 3-4 sample career paths
- [ ] Have job postings ready to show
- [ ] Prepare ethics scenarios for discussion
- [ ] Set up demo order

**In Class:**
- Intro: Explain career assistant
- Students: Create and test reusable instructions; a custom assistant builder is optional
- Demos: 2-3 min demo each (top performers first)
- Discussion: Career opportunities in AI
- End with: Certificate ceremony!

## 🎯 Teaching Tips By Day

### Day 1 Teaching Tips
- Make it fun and exciting!
- Show amazing AI capabilities first
- Don't worry about deep explanations
- Focus on: "AI is for everyone"
- End with enthusiasm, not confusion

### Day 2 Teaching Tips
- Show MANY examples
- Emphasize: Practice makes perfect
- Have students compare prompts in pairs
- Celebrate good prompts loudly
- Competition makes it fun

### Day 3 Teaching Tips
- First real project! Celebrate!
- Document collection is the hardest part
- Tool interfaces change; model the task, show a backup, and let students compare answers with source material
- Troubleshooting is learning
- Demo is the fun part - make it smooth

### Day 4 Teaching Tips
- This day is tricky (automation harder than chatbots)
- Go slower, show more examples
- Let students struggle a bit (learning happens)
- Real-world examples help
- Many will have "aha!" moments

### Day 5 Teaching Tips
- Celebrate their journey
- Projects don't have to be perfect
- Focus on what they learned
- Career discussion is motivating
- End on inspiration high

## 📊 Quick Problem Solver

### Student Can't Access Tool?
→ Project the instructor's demo or use the prepared offline materials; do not share passwords  
→ They follow along on your screen  
→ They do assignment at home later  

### Internet Down?
→ Switch to offline activity (discussion, brainstorm)  
→ Go through slides/content  
→ Conduct Q&A session  

### Student Says "I'm Bored"?
→ "Can you help this student?"  
→ "Try building something more advanced"  
→ "What would you improve?"  

### Student Says "AI Will Replace Me"?
→ "AI changes jobs, not ends careers"  
→ "AI skills are in HIGH demand"  
→ "Learning now = competitive advantage"  

### Student Asks "Is This Hype?"
→ "Great question! Let's verify together"  
→ Show real job postings requiring AI skills  
→ Discuss genuine limitations too  
→ Be balanced and honest

## 📞 Emergency Contact Guidance

**If major technical issue occurs:**

1. **Projector dies:** Use backup plan - discussion, distribute materials digitally
2. **Internet down:** Switch to offline activities from curriculum
3. **AI tool broken:** Use another approved tool or the offline sample and test log
4. **Major confusion:** Slow down, do one activity at a time, simplify scope
5. **Time shortage:** Cut optional content, keep core projects

**Remember:** The goal is learning, not perfection. Adapt as needed!
